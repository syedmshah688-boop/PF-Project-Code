# The Developer's Toolkit (Programming Fundamentals Project)

## Project Overview
A console-based C++ Programming Fundamentals project consisting of:

1. Cryptographic Password Vault
2. Text File Compressor (RLE Engine)

## Development Roadmap

### Phase 1 - Requirements Analysis
- Define project scope
- Identify modules
- Design file storage structure

### Phase 2 - Authentication Module
- Sign Up
- Log In
- Username validation
- File-based storage

### Phase 3 - Password Vault Module
- Caesar Cipher encryption
- Save password
- Retrieve password

### Phase 4 - Text Compressor Module
- Run Length Encoding (RLE)
- File compression
- File decompression

### Phase 5 - Integration & Testing
- Menu integration
- Error handling
- Final testing
